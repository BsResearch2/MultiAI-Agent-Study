# Multi-AI Agent Coordination Study

Private repository for the independent three-agent healthcare coordination research application. This project is completely separate from the algorithmic-control (AC) experiment.

## Status
Research prototype. Do **not** enroll participants until HTTPS hosting, server-side OpenAI API key, persistent database, consent/IRB review, and researcher access security are configured and tested.

## Participant study
Three independent agent conversations: Scheduling, Onboarding & Insurance, and Records & Labs. Participants coordinate information between agents; agents do not automatically communicate. The researcher dashboard provides per-participant events and CSV export.

## Deployment
GitHub stores code only. A Python host with persistent data storage is necessary; GitHub Pages cannot securely run the AI server or private logs.
